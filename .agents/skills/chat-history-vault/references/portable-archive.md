# 可迁移档案与主操作

产品围绕换电脑、离职时带走自己的 AI 记录。`migration_view.rs` 提供“聊天档案 / 备份与迁移”两个工作区，每次默认打开客户端、会话列表、正文三栏；旧的迁移偏好不会再占默认入口。顶部增量导入是快捷操作，迁移页保留收集本机记录、导出档案文件夹、新电脑打开已有档案三步；资源、Skill 和存储清理是辅助入口。

收集窗口列六种本地来源，默认仅文本，点击独立按钮才运行。“自选附件”保留图片、模型、文档、代码、日志、其他六类选择，完整事件快照独立勾选；日志提取要求快照并明确提示。ChatGPT JSON / ZIP 仅作为折叠的可选文件入口，不作为本地扫描来源。窗口水平居中且顶部固定，展开说明不移动主按钮；窄窗口可滚动。清理在独立存储窗口，估算与确认沿用 `archive_storage.py`。阅读区的六类本地客户端、电脑、项目、更新时间常驻，次要条件收进“更多筛选”；会话栏 `↻` 只重读档案。

`starvault transfer-archive --archive /path/to/archive --plan` 检查索引、清单身份、路径和文件大小。以 `--destination /path/to/drive` 代替 `--plan` 执行，在已存在父目录中新建唯一命名的 `StarVault-日期-随机后缀`；目的地不能位于源档案内。桌面先展示检查结果，再选位置导出；范围是当前档案全部来源，与阅读筛选无关。

`archive_transfer.py` 仅复制索引指向的 Markdown、来源索引与说明、已知 records 文件、哈希命名图片附件、Skill 索引及版本 ZIP。不会递归复制整个目录，排除 Git、本机配置、导入缓存和未知文件；不扫描原应用、不补取资源、不创建自动任务或联网同步。导出附使用说明和手动导入策略。新电脑选择整个导出文件夹即可检索阅读，不需要 ZIP 解压，不等于恢复原客户端续聊。

导出共用后端锁，拒绝链接及越界、缺失必要记录、身份不符和空间不足；复制前后复核文件状态。临时目录复制并校验后原子改名，失败不发布半成品、不覆盖原档。保留源档案已有的完整快照与资源，并不强制删除它们。

验证覆盖 `test_archive_transfer.py` 的资源 / Skill / 快照往返、只读估算、配置排除、改写保护、坏路径 / 链接、空间不足与错误 Skill 索引；`test_cli.py` 覆盖统一入口。Rust 覆盖默认工作区、导航点击、980 / 1320 宽度与首页底部入口、检查后导出及忙碌禁用；来源选择继续验证不自动执行。
